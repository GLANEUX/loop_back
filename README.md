# 🎵 Loop — Back-end API

## 🧱 Installation & Lancement

### 1️⃣ Prérequis

- Node.js >= 20.0

### 2️⃣ Installation

```bash
npm install
```

### 3️⃣ Démarrage du serveur

#### Mode développement

```bash
npm run start:dev
```

#### Build + production

```bash
npm run build
npm run start:prod
```

---

## 🧪 Lint, formatage et tests

```bash
# Lint du code
npm run lint

# Correction automatique
npm run lint:fix

# Formatage Prettier
npm run format

# Tests unitaires
npm run test

# Tests e2e
npm run test:e2e
```
